# Research Datasets for the KSCF Study

## Overview

This repository provides the dataset collection associated with the research conducted by Hedayatollah Dallaki and supervised by Dr. Faramarz Safi.

The datasets are provided to support research transparency, facilitate further experimentation, and help researchers reproduce and extend the experiments reported in the associated study.

The dataset collection is distributed as a compressed RAR archive.

## Repository Contents

| File | Description |
|---|---|
| `dataset.rar` | Compressed archive containing the research datasets |

Please extract the archive before using the datasets in your experiments.

## Downloading the Datasets

You can obtain the dataset archive in either of the following ways.

### Option 1: Download from GitHub

1. Open this repository:  
   https://github.com/hdallaki/paper_dataset
2. Click `dataset.rar`.
3. Use the download option to save the archive to your computer.
4. Extract the archive using a compatible utility, such as 7-Zip or WinRAR.

### Option 2: Clone the Repository

If Git is installed on your computer, run:

```bash
git clone https://github.com/hdallaki/paper_dataset.git
```

Then extract `dataset.rar` using a compatible RAR extraction utility.

## Using the Datasets

Before running experiments:

1. Extract the archive.
2. Inspect the extracted files and their directory structure.
3. Consult the documentation and experiment instructions in the main research repository.
4. Place the datasets in the locations expected by the corresponding scripts and configuration files.
5. Follow the instructions in the main repository to execute the experiments.

**Important:** The required directory structure and dataset file formats depend on the implementation and experiment configuration. Please consult the main repository before changing filenames, modifying dataset contents, or preprocessing the data.

## Reproducibility

For reproducible research, users should document the datasets used, any preprocessing operations, experimental configurations, algorithm parameters, and software versions.

To facilitate comparison with the reported results, researchers should preserve the original dataset files and clearly document any modifications made during their experiments.
